# Источники отзывов о ВСП Сбербанка: что реально доступно

Проверено 05.11.2026 живыми анонимными запросами, без входа в учётные записи, с паузой между запросами не меньше 1–1,5 с. Ниже только измеренное. Где проверки не было, так и написано.

**Точка измерения — зарубежный выход в интернет.** Сервисы определяли его по-разному: 2ГИС — как Россию, Яндекс — как один из российских регионов. С российского адреса, например с сервера прода, ответы и пороги защиты могут отличаться. Это надо проверить отдельно.

## 2ГИС — подробно

**Сервис отзывов.**
- Адрес: `public-api.reviews.2gis.com/3.0/branches/{id}/reviews`. Параметры: `limit=50`, `offset`, `sort_by=date_edited`, `fields=meta.providers,meta.branch_rating,meta.branch_reviews_count,meta.total_count,reviews.hiding_reason`, `key`.
- Ключ — `reviewApiKey` из настроек страницы 2gis.ru. Этот же ключ зашит в нескольких открытых проектах.
- Работает только с актуальным браузерным User-Agent. Со старым 2gis.ru уводит на заглушку `/museum`.
- **Параметр `rated` не передаём:** `rated=true` теряет отзывы без оценки, без параметра приходят все.
- Постраничность — `meta.next_link`, внутри это offset. Потолка не нашли: Москва, 912 отзывов, 19 страниц, 26 с.

**Что приходит в отзыве:**
- id, оценка, текст;
- `date_created` и `date_edited`;
- ответ организации с датой;
- провайдер (2gis / flamp / tbank);
- признак скрытия;
- лайки и комментарии;
- автор: имя и публичный id. Имя не храним.
- `user.reviews_count` — число отзывов автора. Нужен для проверки «одноразовых» авторов.

**Поиск отделений.**
- Каталог 2ГИС (`catalog.api.2gis.ru`) с ключом из страницы отвечает `apiKeyIsBlocked`, запросы подписываются. Подпись **не воспроизводим**.
- Используем серверные страницы поиска `2gis.ru/{город}/search/СберБанк/page/N`: 12 объектов на страницу. У каждого есть id, адрес, координаты, организация, рубрики, число отзывов и оценок.
- Банкоматы — отдельная организация «СберБанк, банкомат». Отсеиваются по организации и рубрике.
- 1 111 населённых пунктов с алиасами встроены в HTML 2gis.ru.

**Масштаб.**
- Организация Сбербанка своя в каждом проекте 2ГИС: в Москве — 647 отделений, в малом городе — отдельная организация на одно отделение.
- Поиск отдаёт глубокие страницы: в Москве 1-я, 5-я, 6-я, 20-я и 60-я страницы — каждая с новыми объектами. Обрыва после 5-й страницы, о котором пишут в одном из проектов, на серверных страницах нет.

**Лента отзывов организации** (`/3.0/orgs/{id}/reviews?sort_by=date_edited`, курсор `offset_date`, проверено 05.11):
- отдаёт все отделения организации одним потоком, у каждого отзыва есть `object.id`;
- параметр `fields` не принимает (400);
- по Москве сумма отзывов по отделениям 12 143, итог ленты 12 158 — расхождение 0,1%;
- подходит и для первичной загрузки, и для ежедневной дельты. Пока не реализована.

**2ГИС входит в группу Сбера:** контроль с 2020 года; по сообщениям 2025 года Сбер стал единственным владельцем, точная доля не проверена. Поэтому самый надёжный путь к данным 2ГИС — **договор о данных внутри группы**. Он снимает риски смены ключа и правил сервиса. Сейчас Сбер уже передаёт картам свои данные об отделениях — в карточках Яндекса указан источник «sberbank».

**Серая зона — не используем:**
- старый каталог 2.0 с ключами из старых клиентов. Он отдаёт полный список отделений организации, но ключ не наш.

**Официальный путь:** купить ключ каталога 2ГИС. Нужен только для реестра; отзывы через него не продаются.

## Яндекс Карты — подробно

**Страницы организации.**
- Адрес `yandex.ru/maps/org/{seo}/{id}/reviews/?page=N`. Данные лежат в `<script class="state-view">`, по 50 отзывов на странице.
- Порядок фиксирован — «по релевантности». Параметр `ranking` в адресе игнорируется.
- Страницы 1–12 работают, с 13-й пусто: **потолок 600**.
- Даты создания нет, только `updatedTime`.

**Внутренний сервис `fetchReviews`.**
- Тот же запрос, который делает сайт. Нужны csrf и сессия со страницы и подпись `s` — хэш строки запроса, алгоритм из кода сайта.
- Сортировки: `by_time`, `by_rating_asc`, `by_rating_desc`, `by_relevance_org` и срезы по аспектам. Потолок 600 действует на каждую сортировку.

| Отделение | Заявлено | Получено |
|---|---|---|
| Москва, ул. Вавилова | 1 944 | `by_time` — 600; 4 сортировки — 1 318 (68%); плюс 7 аспектов — 1 485 (76%) |
| Москва, Воздвиженка | 277 | 277 (100%) |
| Кимры | 134 | 134 (100%); повторный проход «только новые» — 1 страница, 7,5 с |
| Кашин | 57 | 57 (100%), только страницы организации |

**Поиск отделений.**
- Сеть 6003612 «Сбербанк России, отделения»; 6003611 — банкоматы, исключаем.
- Страница сети `yandex.ru/maps/213/moscow/chain/sberbank/6003612/?ll=<lon,lat>&z=16` отдаёт до 10–15 ближайших отделений. Префикс региона обязателен, без него ответ 404. Выдачу определяет `ll`.
- Полный обход сети — сетка точек или точки реестра. Ещё не реализовано.

**Ответов банка на Яндексе нет:** поле `businessComment` пусто у всех ~1 950 просмотренных отзывов.

**Номер подразделения по ЦБ в карточке.**
- В признаках карточки есть `nomer_sp_cbr` («1481/1948/115»), `office_type` (для частных лиц / бизнеса / корпоративных клиентов) и дата актуализации. Пометка источника — `aqua_cbr_ru`.
- Номер совпадает с `FILIAL_NUM` реестра ЦБ: 27 из 27 карточек в центре Москвы.
- Это **точная** привязка Яндекс → ЦБ → код ВСП, без сопоставления адресов. Сборщик берёт её первой.
- По стране — пилот 15 городов: номер есть у 154 из 156 карточек, по нему привязано 148. Номер проверяется по реестру: передвижной пункт, КИЦ или другой город — конфликт на разбор, а не привязка.

**Объём.** На 26 отделениях центра Москвы, найденных в обоих источниках, у Яндекса 14 309 текстовых отзывов, у 2ГИС — 1 615, почти в 9 раз меньше. Значит, потолок 600 у Яндекса — главное ограничение полноты, а не частный случай. Только «по новизне» на этих отделениях достаётся 83,8% заявленного.

**Повторы в выдаче.** В выдаче по релевантности один отзыв иногда стоит на двух соседних страницах. Поэтому «получено» считается по разным отзывам за проход, а не по строкам страниц.

## Домклик

- HTML-страницы закрыты Qrator: ответ 401 и JS-проверка. robots.txt и sitemap с того же адреса отдаются — **это не геоблокировка**. Обходить защиту не стали.
- В sitemap нет разделов об офисах, отделениях или отзывах.
- `agencies.domclick.ru` открыт. Там отзывы о **риелторах и агентствах**: «Впечатление клиентов на основе N отзывов», в Москве 20 791 риелтор. Это не отзывы об отделениях банка.
- Открытые парсеры Домклика собирают объявления о недвижимости, а не отзывы.
- Отзывов об ипотечных центрах на Домклике не нашли.
- Нужно согласовать одну проверку с российского адреса (сервер прода). Она покажет, открывается ли HTML без проверки. Но даже тогда отзывов об отделениях там, по всем признакам, нет.

## Что требует согласования

1. `VSP_YANDEX_SIGNED_API=1` — сбор через внутренний сервис Яндекса с подписью запроса.
2. Запуск с IP прода, потому что ограничение источника коснётся всех сборщиков AuditLens. Возможна и одна проверка Домклика с российского адреса.
3. Массовый прогон по всей сети (`sync --all --i-know-this-is-mass`).
4. Платные ключи: каталог 2ГИС или геокодер, если бесплатных справочников не хватит.
5. **Запрос данных 2ГИС внутри группы Сбера.** Это официальный путь вместо публичного ключа сервиса отзывов. Решение и контакт — за владельцем.

## Чего не делаем

- Не решаем капчу.
- Не крутим прокси.
- Не маскируем браузер.
- Не входим под учётными записями.
- Не используем чужие или старые ключи каталога 2ГИС.
- Не обходим Qrator, F5, ServicePipe.
- Не собираем имена и IP авторов. На banki.ru IP автора встроен в HTML отзыва — его не берём.
