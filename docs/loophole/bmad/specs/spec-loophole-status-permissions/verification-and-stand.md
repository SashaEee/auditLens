# Проверка и локальный стенд

## Схема и причина сбоя

`GET /api/loophole/catalog` формирует `LEFT JOIN` с `loophole_preliminary_import`. Локальная БД была остановлена на миграции `059`, поэтому запрос завершался `UndefinedTable` и API возвращал 500. Для актуального контракта применены миграции:

- `060_loophole_preliminary_import.sql` — таблица импорта предварительных записей, используемая каталогом;
- `061_loophole_research_source_publication.sql` — поле даты публикации источника, используемое текущим исследовательским контуром.

Текущий локальный журнал использует `schema_migrations.migration_name`. Миграции фиксируются в этом поле в той же транзакции, что и DDL. Нельзя применять к этому журналу процедуру, рассчитанную на колонку `filename`.

## Тестовые записи каталога

| Банк | Статус | Назначение |
| --- | --- | --- |
| `sberbank` | `preliminary` | Скрытая комиссия за конвертацию средств |
| `tbank` | `published` | Двойной тариф на эквайринг |
| `raiffeisen` | `preliminary` | Некорректное списание штрафов |

Все записи имеют `is_loophole = true`, поэтому отвечают фильтру «Общей базы» и не смешиваются с иными типами данных.

Playwright внутри sandbox не создаёт Windows named pipe и завершается `WinError 5` до старта сценариев. Его результат не используют как доказательство регрессии: тот же точный набор запускается вне sandbox.

## Граница проверки

Полный репозиторный линтер имеет предсуществующие ошибки вне затронутых файлов. Полный `pytest tests` в sandbox также не является итоговым сигналом из-за ограничений Playwright. При изменении этого контракта обязательны адресные серверные и внешние браузерные проверки из таблицы выше, а также `git diff --check`.
