## Intent

Как аналитик,
я хочу выполнять разрешённые аналитические запросы к каталогу,
чтобы получать дополнительные срезы данных без риска изменить их или обойти ограничения доступа.

**Критерии приёмки:**

**Дано** аналитик запускает DB skill,
**Когда** он передаёт запрос,
**Тогда** система принимает только один разобранный оператор `SELECT` к allowlisted views через роль `loophole_readonly`.
**И** параметры передаются отдельно от текста запроса.

**Дано** запрос содержит DML, DDL, несколько операторов, неразрешённую таблицу или функцию,
**Когда** DB skill валидирует запрос,
**Тогда** выполнение блокируется до обращения к БД.
**И** аналитик получает понятное объяснение допустимой формы запроса.

**Дано** разрешённый запрос выполняется успешно,
**Когда** получен результат,
**Тогда** он возвращается как JSON-таблица, пригодная для отображения в интерфейсе.
**И** применяются timeout и жёсткий лимит строк.
