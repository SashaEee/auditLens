## Intent

Как аналитик,
я хочу запустить изолированное исследование через управляемого агента,
чтобы получать полезный ответ без неограниченных действий или записи в общий каталог.

**Критерии приёмки:**

**Дано** аналитик создаёт новое AI-исследование,
**Когда** он отправляет запрос в области поддерживаемых умений,
**Тогда** агент выполняет ReAct-цикл через `AgentFactory` и `SkillRegistry` с allowlisted skills.
**И** максимальное число итераций по умолчанию равно 20 и настраивается без изменения кода.

**Дано** запрос неполный или неоднозначный,
**Когда** агент не может безопасно продолжить,
**Тогда** он показывает уточняющий вопрос и ожидает ответ аналитика.
**И** ожидание ответа не расходует итерацию.

**Дано** достигнут лимит итераций либо один skill вернул некритичную ошибку,
**Когда** агент завершает цикл,
**Тогда** аналитик получает лучший доступный или частичный ответ с понятным объяснением.
**И** ошибка одного skill не приводит к неявному сбою всего исследования.

**Дано** агент выполнил шаги исследования,
**Когда** запуск завершается,
**Тогда** в redacted `agent_audit_log` сохранены пользователь, запрос, инструменты, длительность, результат и `run_id`.
**И** пользователь видит список применённых инструментов без технических аргументов и секретов.
