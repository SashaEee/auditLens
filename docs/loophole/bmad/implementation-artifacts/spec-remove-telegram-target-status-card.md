# Удаление статуса Telegram-целей из управления доступом

## Intent

**Проблема:** экран «Управление доступом» показывал лишнюю карточку статуса Telegram-целей и
зависел от отдельного запроса к Telegram endpoint даже тогда, когда администратору нужны только
роли ЦК КС и сводный аудит.

**Подход:** удалить карточку, её клиентское состояние и запрос из загрузки админ-поверхности;
сохранить серверный Telegram endpoint без изменений и переразложить две оставшиеся карточки по
двум колонкам без пустого ряда.

## Suggested Review Order

1. [Клиентская загрузка и состав админ-поверхности](../../../../src/bank_audit/loophole/static/loophole.jsx#L533) — удалена зависимость UI от Telegram-целей, оставлены роли и аудит.
2. [Сетка двух оставшихся карточек](../../../../src/bank_audit/loophole/static/loophole.css#L1955) — роли и аудит занимают верхний ряд без искусственного растягивания.
3. [Браузерный регрессионный контракт](../../../../tests/loophole/test_final_layout_runtime.py#L463) — две секции, ноль Telegram-запросов и отсутствие удалённого заголовка.
4. [Статический контракт админ-экрана](../../../../tests/loophole/test_admin_roles_audit.py#L593) — fail-closed логика и состав разделов закреплены тестами.
5. [Визуальная верификация](../../../../design-qa.md#L149) — зафиксированы viewport, сравнения, взаимодействия и отсутствие ошибок консоли.
