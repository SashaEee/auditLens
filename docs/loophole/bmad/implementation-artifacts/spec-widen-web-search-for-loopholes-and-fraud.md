## Intent

**Проблема:** Системный промпт управляемого агента ограничивает веб-исследование 2–4 запросами и 3–5 источниками, а мошенничество исключает из периметра. Поэтому отчёт может не охватить достаточно разнообразные публикации по теме и не показывает мошеннические схемы отдельно.

**Подход:** Изменить только системную методологию агента: расширить поиск по независимым кластерам запросов и площадкам, дедуплицировать URL, а подтверждённые публикации о мошенничестве показывать в самостоятельном разделе отчёта, не смешивая их с лазейками.

## Boundaries & Constraints

**Always:** Сохранять жёсткий фильтр `published_at`, нейтральный scope банка и русскую локализацию. Для каждого материала указывать URL и безопасную цитату. Разделять «Лазейки» и «Мошеннические схемы»; не раскрывать ПД и не давать пошаговых инструкций, пригодных для совершения мошенничества.

**Ask First:** Менять контракты структурированного извлечения, классификации, серверной верификации, `loophole_record`, схему БД, лимит итераций агента или параметры поискового инструмента.

**Never:** Не записывать мошенническую схему как `is_loophole`, не передавать её в `audit_extract_loopholes`, не ослаблять правила периода публикации и не создавать git-коммит.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|---------------|----------------------------|----------------|
| Широкое исследование | Запрос о лазейках или мошенничестве | Несколько кластеров разных запросов и площадок, уникальные релевантные URL | Пропускать дубли и нерелевантные материалы |
| Мошеннический материал | Первичный источник подтверждает схему | Отдельный раздел с URL, цитатой, риском и признаками для аудитора | Не извлекать и не сохранять как лазейку |
| Жёсткий период | Источник без `published_at` или вне окна | Материал не учитывается | Честно указать нехватку допустимой фактуры |

**Acceptance Criteria:**
- Given аналитик запрашивает веб-исследование, when агент формирует план поиска, then промпт требует искать разнообразные уникальные публикации через несколько независимых кластеров запросов и площадок, а не останавливаться на первых 2–4 запросах.
- Given материал описывает мошенническую схему, when агент готовит ответ, then материал приведён только в отдельном разделе с URL, безопасной цитатой, риском и признаками для аудитора и не представлен как лазейка или кандидат каталога.
- Given пользователь задал жёсткий период, when источник не имеет точного `published_at` либо не попадает в окно, then он не считается находкой ни в одном разделе.
