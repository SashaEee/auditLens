1. Что меняется

Монолитные tools заменяются шестью skills. Внешний чат не меняет свой контракт.

2. Безопасная расширяемость

SKILL.md описывает skill, но только allowlist в config.json разрешает его factory.

3. Данные и решения

DB skill — только SELECT. Запись проходит через доменные сервисы. Classifier — отдельный шестой skill с batch 50 и не меняет ручные verdict.

4. Безопасный cutover

Старый shim остаётся до успешного паритетного тестирования. Затем его импорты и файл удаляются; двойной архитектуры в production не остаётся.

5. Наблюдаемость

Каждый запуск получает run_id. В agent_audit_log попадают redacted lifecycle-события, но не секреты, токены и полные prompts.
