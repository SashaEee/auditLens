# Макеты модуля «Лазейки»

Дата фиксации: 30 августа 2026 года.

Все файлы ниже являются визуальными макетами. Они не изменяют код приложения и не
подтверждают реализацию показанных сценариев.

## Финальный кандидат

- [`loophole-variant-3-integrated-auditlens-final.png`](loophole-variant-3-integrated-auditlens-final.png)
  — выбранное направление 3, встроенное в светлую оболочку AuditLens; шесть состояний,
  включая добавление веб-источника и CSV-выгрузку выбранных записей.

Зафиксированные решения:

- строка вкладок: «Общая база» → «Добавить источник» → «Новое AI-исследование» →
  «Очередь верификации» → «Управление доступом»;
- «Добавить источник» — самостоятельная вкладка на одном уровне с «Общей базой»;
- CSV — немедленная выгрузка выбранных строк без модального окна импорта;
- в таблицах записей раздельно отображаются «Дата публикации» и «Собрано»;
- единственная метрика уверенности называется «Доверие»;
- поля «Надёжность» и `Trust` не используются;
- основной визуальный язык соответствует светлой палитре AuditLens.

Статус: ожидает подтверждения пользователя.

## Способ подготовки

Макеты подготовлены встроенным Image Gen с визуальными референсами действующего
AuditLens. Финальный edit-промпт сохранял композицию шести экранов и заменял название
вкладки «Парсеры» на «Добавить источник» во всех состояниях.
