- (decision) Scope: только модуль src/bank_audit/loophole/ (loophole.html/css/jsx). Другие модули не трогаем.
- (decision) Форм-фактор: десктоп-веб, диапазон от 1280x720 (малые ноутбуки) до широких мониторов; мобильные <1024 не в скоупе v1.
- (decision) Дизайн-токены модуля приводятся к токенам основного сайта (oklch --paper/--ink/--hair/--accent, радиусы 4/6/10, тени shadow-1/2); добавляется тёмная тема, синхронизированная с html.dark родителя (iframe, same-origin).
- (decision) Внешние CDN (unpkg, Google Fonts) заменяются саморазмещёнными vendor-ресурсами /static/vendor/ как у основного сайта.
- (decision) Результат: DESIGN.md + EXPERIENCE.md, доработки в PRD, затем реализация в модуле лазеек.
- (decision) [2026-08-27] Проблема: на ноутбуке чат и таблица конкурируют за ширину, а старый единый экран противоречит разделению контекстов PRD → Решение: AI-чат доступен только в отдельном контексте исследования; при ширине iframe <1100px он открывается как off-canvas с сохранением диалога.
- (rule) [2026-08-30] Проблема: preflight Product Design искался в корне плагина и завершился ошибкой → Решение: запускать `skills/user-context/scripts/user_context_preflight.py` относительно корня плагина.
- (rule) [2026-08-30] Проблема: шаблон `rg`, начинающийся с `--`, был распознан как флаг → Решение: перед таким шаблоном всегда указывать `-e`.
- (rule) [2026-08-30] Проблема: системный `pytest` не видел проектные зависимости, собирал `_bmad` и не мог писать в системный TEMP → Решение: запускать `F:/auditLens/.venv/Scripts/pytest.exe tests --basetemp=<новый каталог внутри workspace>`; для Playwright на Windows разрешать именованные каналы вне песочницы.
- (rule) [2026-08-30] Проблема: необязательные пути `ruff.toml` и `.ruff.toml` были переданы в `rg` без проверки и дали ошибку отсутствия файла → Решение: сначала получать существующие конфиги через `rg --files` или `Test-Path`.
- (rule) [2026-08-30] Проблема: созданный pytest-каталог не удалился рекурсивно внутри песочницы Windows → Решение: удалять только после проверки абсолютного пути и только в среде с разрешением на этот каталог; отсутствие очистки не маскировать.
