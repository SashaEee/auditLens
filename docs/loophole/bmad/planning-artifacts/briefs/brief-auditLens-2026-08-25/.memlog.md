- (decision) Предмет брифа: авторизация + ролевая модель для модуля Лазейки; читатель — сам Кирилл; режим Coaching path
- (event) Разведка кода: loophole/web.py идентифицирует по клиентскому X-User-Id (подделываемо), основное приложение — Authentik forward-auth (web/auth.py), loophole auth НЕ использует
- (decision) Роли от заказчика: сотрудник ЦК КС — меняет статус лазеек; пользователь лазеек — только просмотр и скачивание; уточняется, кому принадлежит создание парсеров и добавление записей через агента
- (decision) Фундамент: модуль Лазейки переводится на get_current_user из web/auth.py (Authentik forward-auth + dev-fallback), отдельный механизм не строим
- (decision) Источник ролей: локальный маппинг username→role (вариант b), без зависимости от донастройки ОАИТ/групп Authentik
- (decision) Роли (3): администратор модуля Лазейки (назначает роли); сотрудник ЦК КС (меняет статус is_loophole + создаёт парсеры + добавляет записи через агента); пользователь лазеек (просмотр+скачивание)
- (decision) Статус лазейки = существующий ручной вердикт is_loophole (POST /records/verdict), новый workflow-статус не вводим
- (decision) Аутентифицированный пользователь без назначенной роли получает права 'пользователь лазеек' по умолчанию
- (decision) Админ = суперпользователь: наследует права ЦК КС + управление ролями; запрет снятия роли последнего админа
- (decision) Маппинг ролей: таблица в БД + мини-админка для админа в v1 (вариант b); первый админ зашивается миграцией
- (decision) Матрица: чат с агентом read-only доступен пользователю лазеек, добавление записей агентом только ЦК КС; /collect/run, /refine, /clarify — только ЦК КС; /records/backfill-content — только админ
- (decision) Workspaces (workspace/workspaces) — legacy, функционал выпиливается в рамках этой работы
- (decision) Аудит вердиктов: фиксируем changed_by/changed_at при смене статуса is_loophole
- (decision) ЦК КС: 5-7 человек, методологи
- (decision) Критерий успеха добавлен: миграция не ломает существующих — все текущие пользователи стартуют как 'пользователь лазеек'
- (decision) Scope: только модуль Лазейки, основное приложение не трогаем; выпил workspaces — в том же PR
- (override) Vision исправлен заказчиком: локальный маппинг ролей — ЦЕЛЕВОЕ решение, переезд на группы Authentik НЕ планируется
- (event) Полировка: ревью линзами structure+prose, применены 5 правок (дедуп таблицы ролей/матрицы, права админа синхронизированы, тавтология, правило роли по умолчанию вынесено из таблицы, Vision сокращён)
