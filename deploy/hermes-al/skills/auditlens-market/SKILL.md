# Рынок продуктов в AuditLens

## Overview
Вкладка «Рынок» — витрина действующих предложений банков по категориям
(вклады, накопительные счета, кредиты, ипотека, кредитные и дебетовые карты,
автокредиты, РКО) и ранг Сбера по **метрике категории**. Инструменты
`mcp_auditlens_market_position` и `mcp_auditlens_market_offers` отдают ровно эти
данные.

## When to Use
- «Какое место Сбер по вкладам», «чем мы хуже рынка», «слабые места».
- «Сравни наши вклады с ВТБ и Газпромбанком», «лучшие кредиты рынка».
- Don't use for: условия одного продукта из тарифа (это `knowledge_search`),
  жалобы на продукт (auditlens-complaints).

## Метрика категории — чем сравнивают
| Категория | Метрика | Лучше |
|---|---|---|
| Вклады, накопительные | эффективная ставка | больше |
| Кредиты | **ПСК от** (полная стоимость, 353-ФЗ), не рекламная ставка | меньше |
| Ипотека | ставка от (льготные госпрограммы исключены) | меньше |
| Кредитные карты | грейс-период, дни | больше |
| Дебетовые карты | обслуживание, ₽/год | меньше |
| РКО | обслуживание, ₽/мес | меньше |

## Как отвечать
1. Позиция — `market_position(category)`: ранг из скольки, продукт и значение
   Сбера, разрыв с медианой и лидером, сегменты (`comparable`: массовые,
   пенсионные…), оговорки (`method_caveats`, `degenerate`, `teaser`).
2. Сравнение с банками — `market_offers(category, banks=[…])`: лучшие 3–5
   предложений каждого банка. Сравнивай сопоставимое: срок, сумму, сегмент,
   условия ставки (`rate_requires`, `attain`).
3. Вывод формулируй с оговорками: ставка на 3 месяца — промо-срок, а не
   базовая доходность; пенсионный вклад сравнивай с пенсионными.
Готово, когда: названы ранг и значения с продуктами, сравнение в таблице,
оговорки о сроке/условиях/сегменте есть там, где они меняют вывод.

## Common Pitfalls
1. Сравнивать кредиты по рекламной «ставке от» — у половины лидеров ПСК выше
   на 5+ п.п. Для кредитов — ПСК.
2. Лучший вклад Сбера с коротким сроком выдавать за «Сбер платит больше всех»
   без оговорки про срок и условия.
3. `implausible_reason` у предложения — число под сомнением (сторож
   правдоподобия), в вывод его не ставь или помечай.
4. «Предложений банка нет» в витрине ≠ «продукта у банка нет»: витрина собирает
   не всё. Проверь `knowledge_search` или сайт банка.
5. Разница ставок — в п.п., не в процентах.

## Verification Checklist
- [ ] Метрика соответствует категории (ПСК для кредитов).
- [ ] У каждого числа — продукт, срок и дата витрины (`as_of`/`valid_from`).
- [ ] Ссылка на «Рынок» (`link`) и на условия продукта (`url`).
